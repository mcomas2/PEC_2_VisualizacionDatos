# PEC_2_VisualizacionDatos

---
## Introduccion
Este repositorio muestra 3 diferentes tipos de visualizaciones que se han asignado para la PEC2 en la asignatura de Visualizacion de datos de la UOC

## TÉCNICA GRUPO I (Básicas y populares): Timeline
- Descripción: El objetivo de la visualización es mostrar la evolución de los precios de la primera vivienda nueva a lo largo del tiempo, utilizando como referencia una base del año 2015.
- Herramienta usada: Tableau
- URL: https://drive.google.com/file/d/1GV8NECCtPfsLU0BwlidIZvyad24W2PvC/view?usp=drive_link

## TÉCNICA GRUPO II (Habituales y específicas): Sunburst
- Descripción: Visualización jerárquica que muestra cómo se distribuyen los niveles de estrés entre diferentes plataformas digitales, permitiendo ver fácilmente qué grupos están más afectados y sus proporciones relativas.
- Herramienta usada: Tableau
- URL: https://drive.google.com/file/d/1vF8BSJ7nH9ez02gd7y7F-ZwlGBXv3Bzr/view?usp=drive_link

## TÉCNICA GRUPO III (Menos habituales o específicas): Isotype & Unit charts
- Descripción: La visualización representa la cantidad y proporción de personas según su nivel de felicidad al usar plataformas digitales, diferenciadas por grupos de edad.
- Herramienta usada: Flourish
- URL: https://public.flourish.studio/story/3427769/
